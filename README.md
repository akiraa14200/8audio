# 8 Audio

A fresh native Android music-player implementation informed by the provided ArchiveTune 13.2.0 archive. This repository builds its own source and does not fetch ArchiveTune during CI.

Current foundation: Jetpack Compose dark UI, Saavn song search, artwork, background Media3 playback and notification controls. Run **Build 8 Audio APK** in GitHub Actions to build the debug APK.
